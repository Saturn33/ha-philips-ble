# BLE Mesh Lights

Home Assistant integration for remote-only Bluetooth Mesh ceiling lights, controlled through ESP32 boards running ESPHome. The first supported device is the Philips Valen series. What is known about its protocol is in [docs/PROTOCOL.md](docs/PROTOCOL.md); accepted limitations of the code are in [docs/KNOWN_ISSUES.md](docs/KNOWN_ISSUES.md).

**Work in progress:** not usable yet.
